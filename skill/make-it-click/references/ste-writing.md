# Writing in the style of ASD-STE100 (Simplified Technical English)

ASD-STE100 is a controlled language specification. It was first made for aircraft
maintenance documentation. It limits words, sentence length, and grammar so that text has
one meaning and is easy to read, also for readers whose first language is not English.

This file is a working summary written for this skill. It is not the specification. The
official specification and its dictionary come from ASD (asd-ste100.org). Use the official
document when the user needs real compliance.

## Sentence rules

- Procedural sentences (instructions): maximum 20 words.
- Descriptive sentences (explanations): maximum 25 words.
- Paragraphs: maximum 6 sentences. One topic per paragraph.
- One instruction per sentence. Exception: two actions done at the same time.
- Put conditions first: "If the light comes on, stop the pump."
- Use vertical lists for complex text and for sequences of steps.

## Verb rules

- Use the active voice in instructions. In descriptive text, use the passive only when
  the doer is not known or not important.
- Use these forms: imperative, simple present, simple past, simple future, infinitive,
  and the past participle as an adjective ("the closed valve").
- Do not use the -ing form, except inside a technical name ("landing gear").
- Do not use perfect or progressive tenses ("has closed", "is closing").
- Do not use phrasal verbs when a single verb exists ("set up" -> "install", "find out" -> "find").
- Write commands in the imperative: "Close the valve."

## Word rules

- One word, one meaning. Use each approved word only as its approved part of speech.
- Use the same word for the same thing every time. Do not use synonyms for variety.
- Keep articles ("the", "a") and words like "this". Do not write in telegraph style.
- Noun clusters: maximum 3 words. Break longer clusters up with "of", "for", or a relative
  clause: "pump outlet pressure sensor" -> "the sensor for the pressure at the pump outlet".
- Technical names and technical verbs from the user's domain are allowed. Define each one
  the first time you use it if the reader may not know it.

## Common substitutions

A short, non-exhaustive set of examples. The official dictionary is the authority.

| Avoid | Use |
|---|---|
| in order to | to |
| utilize | use |
| commence, initiate | start |
| terminate | stop |
| ensure | make sure |
| prior to | before |
| approximately | about |
| subsequently | then, after |
| facilitate | help, make ... easy |
| numerous | many |
| sufficient | enough |
| it is necessary that you | you must |

## Safety notes

Start with a clear, simple command. Then give the risk.

- WARNING: risk of injury or death.
- CAUTION: risk of damage to equipment.

Example: "WARNING: Do not touch the brake unit until it is cool. Hot parts can cause injury."

## Rewriting procedure

1. Find the main point. Write it as the first sentence.
2. Split each sentence that has more than one idea.
3. Change passive instructions to active commands.
4. Replace -ing forms, perfect tenses, and phrasal verbs.
5. Replace complex words with simple words (see the table).
6. Break noun clusters longer than 3 words.
7. Check that each term has one meaning in the whole text.
8. Count words. Shorten each sentence that is over the limit.

## Example

Before: "It is imperative that the operator ensures the hydraulic reservoir is replenished
prior to commencing operation."

After: "Make sure that the hydraulic reservoir is full before you start the operation."
